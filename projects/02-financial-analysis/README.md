# Project 02 — Financial Performance & Profitability Analysis

**Área:** Análise financeira  
**Estado:** Planeado

## Objectivo
Analisar receitas, despesas, custos e rentabilidade para compreender a saúde financeira de uma organização e apoiar decisões de gestão.

## Análises previstas
- Evolução de receitas e despesas.
- Comparação entre orçamento e valores realizados.
- Rentabilidade por unidade, produto ou serviço.
- Margens e tendências financeiras.

## Ferramentas previstas
Excel, Power Query, Power BI e SQL.

## Nota sobre os dados
A origem e a natureza dos dados (públicos, fictícios ou anonimizados) serão identificadas quando o projecto for desenvolvido.
