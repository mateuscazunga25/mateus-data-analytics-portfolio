# Project 05 — Inventory & Product Performance Analysis

**Área:** Gestão de stocks e desempenho de produtos  
**Estado:** Planeado

## Objectivo
Avaliar níveis de stock, movimentação de produtos e desempenho para apoiar decisões de aprovisionamento e reduzir rupturas ou excesso de inventário.

## Análises previstas
- Entradas, saídas e saldo de stock.
- Produtos com maior e menor rotação.
- Rupturas e excesso de stock.
- Indicadores de cobertura e reposição, se os dados permitirem.

## Ferramentas previstas
Excel, Power Query, Power BI e SQL.

## Nota sobre os dados
A origem e a natureza dos dados (públicos, fictícios ou anonimizados) serão identificadas quando o projecto for desenvolvido.
