# Data Analytics Portfolio

Portfólio profissional de Análise de Dados, com projectos práticos desenvolvidos em **Excel, Power Query, Power BI e SQL**.

## Sobre este portfólio

Este repositório reúne estudos de caso de análise de dados orientados para problemas de negócio. Cada projecto documenta o problema, os objectivos, a preparação dos dados, a análise, os indicadores-chave (KPIs), os resultados e as recomendações.

## Projectos

| Nº | Projecto | Área | Estado |
|---|---|---|---|
| 01 | TechDistrib Angola — Electronic Sales Performance Analysis | Vendas e desempenho comercial | Em preparação |
| 02 | Financial Performance & Profitability Analysis | Análise financeira | Planeado |
| 03 | Customer & Telecom Analytics | Clientes e telecomunicações | Planeado |
| 04 | HR Analytics | Recursos humanos | Planeado |
| 05 | Inventory & Product Performance Analysis | Stocks e produtos | Planeado |
| 06 | Integrated Business Intelligence | Análise integrada de negócio | Planeado |

## Ferramentas

- **Excel:** análise, fórmulas, tabelas dinâmicas e dashboards.
- **Power Query:** limpeza, transformação e preparação de dados.
- **Power BI:** modelação de dados, KPIs e dashboards interactivos.
- **SQL:** consulta e análise de bases de dados.
